Poly GTA is a low-poly open-world crime game set in the city of Solmar. Drive around the city, steal cars, outrun police chases, build up wanted stars, and work through 3 missions.

## How to run

```sh
node serve.ts
```

Then open http://localhost:8080 in desktop Chrome.

## Controls

- **WASD** — walk / drive
- **Mouse drag** — camera
- **E** — steal a car
- **F** — shoot
- **H** — horn
- **P** — pause

## Missions

1. **First Wheels** — steal a car and drive to the docks (+$500)
2. **Beach Run** — deliver a package to the pier (+$500)
3. **Heat Wave** — escape to the safehouse (+$500)

Finish all three missions to win. Your best score is saved in the browser.
